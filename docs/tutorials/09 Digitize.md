# Tutorial · Digitize a map into a shapefile

_About 5 minutes._

1. Open a map PDF and choose **Digitize → Map**.
2. Pick the coordinate system, for example **UTM 43N**.
3. Click **Add reference point** two or three times on known places and type their coordinates.
4. Choose **Line** (or Point / Area) and click along the feature; press **Enter** to finish. Drag a vertex to adjust it.
5. Give features a value (depth, elevation) if you need it.
6. Export as **Shapefile**, GeoJSON, KML, DXF, or a Delft3D **.ldb** land boundary.

For graphs: choose **Graph**, set two ticks on each axis, then click the points to get their numbers.
