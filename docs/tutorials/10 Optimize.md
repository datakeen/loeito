# Tutorial · Make a file smaller

_About 1 minute._

1. Choose **Optimize** and click **Look inside**. The bar shows what takes the space: images, fonts, page drawings, structure.
2. Read the tip under it; it says what will help most.
3. Pick **Balanced** (150 dpi, good quality) or **Smallest** (96 dpi, email-friendly), and click **Measure**.
4. Happy with the size? **Save copy**. The main Save uses these settings too.
