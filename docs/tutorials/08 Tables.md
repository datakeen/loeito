# Tutorial · Get a table into Excel

_About 2 minutes._

1. Open `Input/Time Table- Fall 2026 - V3.pdf` and choose **Tables**.
2. Click **Find tables**, or drag a box around the table.
3. Check the preview; merged cells are kept.
4. Click **Excel** for a styled workbook, **CSV** for data, or **Copy** to paste straight into Word or Excel.
5. For scans, leave the text source on *Auto*: Loeito reads each cell separately.
