# Tutorial · Pages: rotate, reorder, split

_About 2 minutes._

1. Open a PDF and choose **Pages**. All pages appear as cards; the page list on the left slides away because you don't need it here.
2. Hover any page and click its **rotate** button. It turns at once, with no need to select it first.
3. Click a page, **Ctrl-click** two more, or drag a rectangle across several on empty space. Press **R** to rotate them all.
4. Drag a page to a new place; the others glide aside.
5. Make the cards bigger with the slider at the bottom (or Ctrl-wheel). At large sizes the page list comes back.
6. Select a few pages and press **→** or **↓**. They step along, and **Home** sends them to the start. **Ctrl X**, then select another page and **Ctrl V**, moves them after it (Ctrl C copies instead).
7. Click **Odd** to select every odd page, then **Rotate → Right**.
8. Type `1-3` in the range box and click **Select**; then **Send to another document → Copy** puts them into a new tab.
9. **Split** saves the document in parts: odd/even, every N pages, ranges, or one file per page.
10. To combine whole files, use **Merge PDFs…** (see the Merge tutorial).
