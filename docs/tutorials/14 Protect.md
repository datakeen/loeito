# Tutorial · Share a document safely

_About 2 minutes._

1. Choose **Protect**.
2. Type a name that must not be shared, and click **CNIC numbers** and **Phone numbers**. Click **Find**.
3. Check the red boxes on the pages and untick anything you want to keep. Click **Black out**.
4. Under *Hidden information*, click **Inspect this document** and read the list.
5. Under **Password**, type a password twice, untick *Copy text* if you like, and click **Protect when saving**. Then **Save**: the file now asks for the password.
6. Click **Save a clean copy for sharing…**. Loeito removes the details, comments, attached files and scripts, and the blacked-out text is truly gone.
