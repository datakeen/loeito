# Tutorial · Make a scan searchable (OCR)

_About 2 minutes, plus reading time for long scans._

1. Open a scanned PDF (try `Input/CDA Bylaws.pdf`) and choose **Searchable**.
2. Pick the language, then **Make searchable** (this page or all pages).
3. When it finishes, pages show an **OCR** badge. Press **Ctrl F** and search for a word.
4. Save. The page looks exactly the same, but the text can now be selected, searched and copied.
