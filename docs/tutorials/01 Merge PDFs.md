# Tutorial · Merge PDFs

_About 2 minutes. You need two or more PDFs (the files in `samples/` or `Input/` work well)._

1. On the welcome screen, click **Merge PDFs**. Or, with a document open (even one you have edited), use **Pages → Merge this with other files…**: it comes in first, with its edits.
2. Click the files **in the order you want them** (Ctrl-click to pick several), then **Open**. Each file appears as a numbered card with a preview, its page count and size.
3. Hover over a preview. A card shows the title, author, the date it was created and changed, the paper size and the folder.
4. **Change the order:** drag a card by its header, or use the ↑ ↓ buttons. The cards glide into place.
5. Click **Show pages** on a file. Click a page to select it; Shift-click selects a range, Ctrl-click adds pages.
6. **Rearrange pages:**
   - drag pages within a file or onto another file; a blue line shows where they will land;
   - hold **Ctrl** while dropping to copy instead of move;
   - or use **Cut / Copy** in the bar at the bottom, then click a **+** between pages, or **Paste at start / end** on any file.
7. **Rotate** with the bar's Left / Right buttons, the buttons on each page, or the **R** key. **Delete** removes pages. **Ctrl Z** undoes.
8. **More than PDFs:** use *Add files* for pictures, or for Word, Excel and PowerPoint files (they need Loeito started with Start Loeito.cmd). Click **Cover…** to put a designed front cover at the start or a last page at the end.
9. **Whole files:** click a card's **copy** button, then a *Paste file…* slot (start, between files, end). The **duplicate** button adds a copy right after it.
10. Type a name next to **Save as**. Click the folder button to choose where it goes (normally the folder of the first file).
11. Click **Merge & Open** (or press Ctrl Enter). Loeito saves the file and opens it in a new tab so you can check it. *Show in folder* is in the message that appears.

**Tip:** need to check something elsewhere? Click **Back to Loeito**. The *Merge waiting* bar returns you to the merge exactly as it was. You can also drop files from Explorer straight onto the workspace.
