# Tutorial · Document properties and metadata

_About 1 minute._

1. Open a PDF and click its **name** at the top (or press **Ctrl K** and type *properties*).
2. Look at **Check** at the bottom. It lists what's missing or untidy, for example *No language* or *Title is ALL CAPS*.
3. Click **Tidy up everything**, or the **Fix** button next to each item.
4. Add an **Author** and a few **Keywords** (*bylaws, zoning, Islamabad*).
5. Under *Your own fields*, click **+ Add a field**: *Project* = *Master plan 2026*.
6. Open *What the original file said* to compare with the original.
7. Click **Done**, then **Save**. The details are now inside the PDF and show in Windows Explorer, Acrobat and search tools.
