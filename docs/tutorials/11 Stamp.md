# Tutorial · Page numbers, headers and footers

_About 2 minutes._

1. Choose **Stamp** and switch on **Page numbers**. Pick *Page 1 of 12* and the bottom-right position.
2. Under **On pages**, set **Skip first** to 2 so the cover and the contents pages have no number. *Count from* the first numbered page: page 3 shows "Page 1".
3. Switch on **Header**. Type `{title}` in Left and `Draft` in Right; tick *Thin line under the header*.
4. Tick **Mirror left ↔ right on even pages** for a book layout.
5. **Drag the page number** on the page to where you want it. In the little menu, choose *Move it on all pages*, or *Only on this page*.
6. If the document mixes portrait and landscape pages, tick **Scale with the page**, or click a size chip under *On pages*.
7. Flip through the pages: everything is previewed live. Save to write it in.

**Bates numbers:** pick the *Bates number* style, set a prefix, then **Continue across all open documents** and **Save all to a folder…**.
