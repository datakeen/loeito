# Tutorial · Open, save and Save As

_About 2 minutes._

1. Press **Ctrl O**. In the Open sheet, pick a place on the left (Desktop, Documents, a drive), double-click folders, and choose a file. Each file opens in its own tab.
2. Make a small change, for example rotate a page with **Ctrl R**.
3. Press **Ctrl S**. Loeito asks *Save changes to the original?*. Press **Enter** to save. The old version is kept as a safety copy for 30 days.
4. Prefer a copy? Press **Ctrl Shift S** for Save As:
   - type a new name, or click a suggestion;
   - click **New folder**, type a name, press Enter (Loeito goes into it);
   - press **Save**. If the name already exists, choose *Replace* or *Keep both*.
5. Click **Show in folder** in the message to see the file in Explorer.

**Tip:** your last files are listed under **Recent** on the welcome screen.
